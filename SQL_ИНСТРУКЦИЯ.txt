КАК НАСТРОИТЬ БАЗУ SUPABASE

1. Открой https://supabase.com/dashboard/project/gfjbpljdoazpfjlequqv/sql/new
2. Войди в аккаунт, если попросит.
3. Должна открыться страница SQL Editor с большим полем для SQL и кнопкой Run.
4. В PyCharm открой файл SUPABASE_SETUP.sql в корне проекта.
5. Нажми Ctrl+A, затем Ctrl+C.
6. Вернись в SQL Editor, щёлкни в большое поле, нажми Ctrl+A, затем Ctrl+V.
7. Нажми Run. Дождись результата.

ВАЖНО:
- Не выбирай Logs query / Logs Explorer: это просмотр логов, там разрешён только SELECT.
- Не запускай SQL в терминале PyCharm.
- Не удаляй таблицы и не запускай DROP TABLE.
- Если видишь Error, скопируй сюда весь текст ошибки.
- Если видишь Success, обнови сайт Ctrl+F5 и проверь публикацию поста и истории.

Этот SQL объединяет миграции самого проекта: профили, чаты, настройки, устройства, медиа сообщений, фото профиля, истории, посты, лайки, комментарии и Storage.
